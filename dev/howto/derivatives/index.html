Time derivatives

CSPICE returns a position and its first derivative. This package returns derivatives of any order, in two ways that give the same numbers to rounding: a direct call, and automatic differentiation through the ordinary calls.

Direct calls

spkder returns the position of a target relative to an observer and its first N time derivatives, and pxder does the same for a rotation matrix. The order is a Val, so that the result is a tuple of static arrays; with names in upper case, as below, the call allocates no memory.

using Allspice

et = str2et("2025 MAR 01 12:00:00 UTC")
position, velocity, acceleration = spkder("PROBE", et, "J2000", "EARTH", Val(2))
acceleration                                # geometric, km/s^2
3-element StaticArraysCore.SVector{3, Float64} with indices SOneTo(3):
  0.0004755589731846914
 -7.11500097493428e-5
 -0.00019556584804662536

Without a correction argument the result is geometric, and its second element is the velocity that spkezr returns. An aberration correction goes before the observer:

spkder("PROBE", et, "J2000", "LT+S", "EARTH", Val(2))[3]    # as seen from the Earth, km/s^2
3-element StaticArraysCore.SVector{3, Float64} with indices SOneTo(3):
  0.0004755669303776254
 -7.11149144817008e-5
 -0.00019555402797787023
rotation, rate = pxder("J2000", "IAU_EARTH", et, Val(1))
rate[1, 1]                                  # 1/s
2.5965684603416687e-5

Dual-number epochs

With ForwardDiff.jl loaded, the epoch can be a ForwardDiff.Dual in these calls:

  • the states: spkezr, spkpos, spkgeo, spkssb, the integer-ID forms, spkltc, spkaps, spkapo, spkacs, spkcpo, spkcpt, spkcvo and spkcvt;
  • the rotations pxform, sxform and pxfrm2;
  • spkder, pxder and the table queries;
  • the surface calls subpnt, subslr, sincpt, ilumin, illumg, illumf, phaseq and azlcpo;
  • the time conversions unitim and deltet.

Other calls, such as limbpt, termpt, tangpt, occult, fovtrg and et2lst, take a plain real epoch and throw SpiceError(:badarg) for a Dual. An event search takes a window of Float64 epochs.

A function built from the calls of the list can be differentiated as a whole, and an optimizer can differentiate through an acceleration from spkder. The derivative of the corrected position below includes the change of the light time.

using ForwardDiff

apparent(t) = spkpos("PROBE", t, "IAU_EARTH", "LT+S", "EARTH")[1]
ForwardDiff.derivative(apparent, et)        # km/s in the rotating frame
3-element StaticArraysCore.SVector{3, Float64} with indices SOneTo(3):
  2.0891721527600877
 -0.060112347094381784
 -1.6752175239747333

Order 1 and the velocity of spkezr

Order 0 of spkder and of pxder is the result of spkpos and of pxform. For a geometric position, order 1 is the velocity that spkezr returns, and each higher order is a derivative of that velocity. With the LT corrections (LT, LT+S, XLT, XLT+S), CSPICE approximates the rate of the light time, so that order 1 differs from the velocity of spkezr by about 1e-8 relative for the Moon seen from the Earth; with the CN corrections the two agree to about 1e-13 relative. For some frames, order 1 of pxder likewise differs from the derivative block of sxform, which follows the rates of CSPICE. Exact derivatives and the rates of CSPICE gives the function that is differentiated for each correction and each kind of frame.
