Frames and orientation

Rotations between frames

Allspice.pxform — Function
pxform([ctx,] from, to, et) -> SMatrix{3,3}

Return the matrix that rotates a position vector from frame from to frame to at et, as pxform_c.

For the matrix R, R * v gives in to the components of a vector v given in from. from and to are frame names or frame IDs. et is in seconds past J2000 TDB. The frame classes of CSPICE are supported: inertial, PCK, CK, fixed offset, dynamic and switch frames (a switch frame takes one of several base frames by epoch). Two inertial frames need no kernel. With ForwardDiff loaded, et can be a dual number.

Throws SpiceError:

  • :unknownframe if a frame name is not known;
  • :badarg if et is not finite;
  • :framedatanotfound if the definition or the constants of a frame are not loaded (the BODY<id>_PM variables of a PCK frame);
  • the error kinds of tkfram for a fixed-offset frame whose definition is incomplete or not valid;
  • :noframeconnect if a CK frame has no pointing or no clock kernel at et, or a switch frame has no base there;
  • :valueoutofrange if et is outside the range of the clock of a CK frame.

Examples

julia> R = pxform("J2000", "ECLIPJ2000", 0.0);

julia> round.(R; digits=6)
3×3 StaticArraysCore.SMatrix{3, 3, Float64, 9} with indices SOneTo(3)×SOneTo(3):
 1.0   0.0       0.0
 0.0   0.917482  0.397777
 0.0  -0.397777  0.917482

With a planetary constants kernel loaded:

furnsh("pck00011.tpc")
et = 0.0                                # seconds past J2000 TDB
r_inertial = [7000.0, 0.0, 0.0]         # km, in J2000
R = pxform("J2000", "IAU_EARTH", et)
r_fixed = R * r_inertial

See also sxform, pxder.

Allspice.pxfrm2 — Function
pxfrm2([ctx,] from, to, etfrom, etto) -> SMatrix{3,3}

Return the matrix that rotates a position vector from frame from at the epoch etfrom to frame to at the epoch etto, as pxfrm2_c of CSPICE.

The matrix is the product of the rotation from from to J2000 at etfrom and the rotation from J2000 to to at etto. It is the rotation that the light-time corrections need, where the frames of the observer and of the target are evaluated at different epochs. The arguments and the errors are those of pxform; with etfrom == etto the result is the matrix of pxform to rounding.

Examples

julia> R = pxfrm2(SpiceContext(), "J2000", "ECLIPJ2000", 0.0, 1.0e9);

julia> R == pxform(SpiceContext(), "J2000", "ECLIPJ2000", 0.0)    # inertial frames
true

See also pxform, spkcpt.

Allspice.sxform — Function
sxform([ctx,] from, to, et) -> SMatrix{6,6}

Return the matrix that transforms a state (position, velocity) from frame from to frame to at et, as sxform_c.

The matrix is [R 0; dR R]: R is the rotation of pxform and dR is its time derivative in 1/s. from and to are frame names or frame IDs; et is in seconds past J2000 TDB.

dR is the rate that CSPICE gives. For a CK frame it comes from the angular velocity of the CK segment, and only segments with angular velocity are used. For CK frames, some dynamic frames and switch frames, which pxder lists, dR can differ from the exact derivative of R; order 1 of pxder gives that.

Throws the errors of pxform.

Examples

furnsh("naif0012.tls")
furnsh("pck00011.tpc")
et = str2et("2025-03-01T12:00:00")
X = sxform("J2000", "IAU_MARS", et)
state_inertial = [3500.0, 0.0, 0.0, 0.0, 2.0, 0.0]     # km, km/s, in J2000
state_fixed = X * state_inertial       # km, km/s

See also pxform, pxder.

Frame information

Allspice.frinfo — Function
frinfo([ctx,] frcode) -> Union{Nothing,Tuple{Int,Int,Int}}

Return (center, class, classid) of the frame with ID frcode, as frinfo_c, or nothing if the frame is not known.

center is the NAIF ID of the body at the frame origin. class is 1 for inertial, 2 for PCK, 3 for CK, 4 for fixed offset, 5 for dynamic and 6 for switch frames; classid is the ID of the frame inside its class. A built-in frame has priority over a frame of the kernel pool. An ID in 13000:13999 without a definition is a PCK frame of the Earth with the class ID frcode - 10000, as in CSPICE. nothing takes the place of the found flag.

Examples

julia> frinfo(namfrm("IAU_EARTH")), frinfo(-999)
((399, 2, 399), nothing)

See also namfrm, ccifrm.

Allspice.cidfrm — Function
cidfrm([ctx,] cent) -> Union{Nothing,Tuple{Int,String}}

Return (frcode, frname) of the frame that is associated with the body with ID cent, as cidfrm_c, or nothing if there is none.

The kernel-pool variable OBJECT_<cent>_FRAME (or OBJECT_<name>_FRAME) has priority. Without it the answer is IAU_EARTH for the Earth, and otherwise a built-in frame whose center is cent. For a center with several built-in frames the answer is the frame that CSPICE gives. nothing takes the place of the found flag.

Examples

julia> cidfrm(499)
(10014, "IAU_MARS")

Allspice.tkfram — Function
tkfram([ctx,] frcode) -> Tuple{SMatrix{3,3,Float64,9},Int}

Return (rot, relative) of the fixed-offset (class 4) frame with the class ID frcode, as tkfram_c. frcode is the value of FRAME_<id>_CLASS_ID.

rot rotates a vector from the frame to its relative frame, the frame with ID relative; this is the meaning of TKFRAME_<frcode>_MATRIX. The definition comes from the TKFRAME_<frcode>_* variables of the kernel pool, or from the TKFRAME_<name>_* variables, where <name> is the name of the frame with the ID frcode, as in CSPICE. A TK frame whose class ID is not its frame ID therefore needs another frame with that ID, in CSPICE as here.

Throws SpiceError:

  • :zeroframeid if frcode == 0;
  • :incompleteframe if no frame has the ID frcode;
  • :competingframespec if a variable is present in both forms;
  • :variablenotfound, :badvariablesize or :badvariabletype if a variable that the definition needs is missing, has the wrong number of values or the wrong type;
  • :badframespec if the relative frame is not known, :badframespec2 if it is the frame itself;
  • :unknownframespec if TKFRAME_<frcode>_SPEC is not MATRIX, ANGLES or QUATERNION;
  • :unitsnotrec or :incompatibleunits if TKFRAME_<frcode>_UNITS is not an angle unit, and :badaxisnumbers if an axis is not 1, 2 or 3.

pxform and the other calls that pass through such a frame throw the same.

Examples

julia> ctx = SpiceContext();

julia> lmpool(ctx, ["FRAME_TOPO = -1000", "FRAME_-1000_NAME = 'TOPO'",
                    "FRAME_-1000_CLASS = 4", "FRAME_-1000_CLASS_ID = -1000",
                    "FRAME_-1000_CENTER = 399", "TKFRAME_-1000_RELATIVE = 'J2000'",
                    "TKFRAME_-1000_SPEC = 'ANGLES'", "TKFRAME_-1000_ANGLES = (0, 0, 90)",
                    "TKFRAME_-1000_AXES = (1, 2, 3)", "TKFRAME_-1000_UNITS = 'DEGREES'"])

julia> rot, relative = tkfram(ctx, -1000);

julia> relative, round.(rot; digits=12) == [0 1 0; -1 0 0; 0 0 1]
(1, true)

julia> pdpool(ctx, "TKFRAME_-1000_AXES", [1.0, 2.0]);

julia> try tkfram(ctx, -1000) catch err; err.kind end
:badvariablesize

Allspice.tipbod — Function
tipbod([ctx,] ref, body, et) -> SMatrix{3,3}

Return the matrix that rotates a position vector from the inertial frame ref to the body-fixed frame of body at et, as tipbod_c.

ref is the name or the ID of a built-in inertial frame. body is a NAIF body ID, or the frame class ID of a binary PCK frame, the ID that its segments carry (31008 for MOON_PA_DE440). et is in seconds past J2000 TDB. A binary PCK has priority over the constants of a text PCK.

Throws SpiceError(:irfnotrec) if ref is not a built-in inertial frame, SpiceError(:badarg) if et is not finite, and SpiceError(:framedatanotfound) if no PCK data are loaded for the body.

See also tisbod, pxform.

Allspice.kplfrm — Function
kplfrm([ctx,] frmcls) -> Vector{Int}

Return the IDs of the frames of the class frmcls that the kernel pool defines, in increasing order and without duplicates, as kplfrm_c of CSPICE.

frmcls is a frame class of frinfo (1 to 6), or -1 for every class. As in CSPICE, a frame is listed if the pool has

  • FRAME_<name> = <id>, for the value <name> of a FRAME_*_NAME variable;
  • FRAME_<id>_NAME;
  • FRAME_<id>_CLASS or FRAME_<name>_CLASS.

The other variables of a frame definition are not checked, so an ID can be listed that frinfo does not know. The built-in frames are not included unless the pool defines them; bltfrm gives those.

Throws SpiceError(:badframeclass) if frmcls is not -1 or a class 1 to 6.

Examples

julia> ctx = SpiceContext();

julia> lmpool(ctx, ["FRAME_TOPO = 1500001", "FRAME_1500001_NAME = 'TOPO'",
                    "FRAME_1500001_CLASS = 4", "FRAME_1500001_CLASS_ID = 1500001",
                    "FRAME_1500001_CENTER = 399"]);

julia> kplfrm(ctx, 4), kplfrm(ctx, 3)
([1500001], Int64[])

Orientation from C-kernels

Allspice.ckgp — Function
ckgp([ctx,] inst, sclkdp, tol, ref) -> Union{Nothing,Tuple{SMatrix{3,3},Float64}}

Return the pointing of the instrument or structure inst at the encoded spacecraft clock value sclkdp, as ckgp_c.

  • inst: CK ID of the instrument or structure.
  • sclkdp: encoded spacecraft clock, in ticks (see sce2c).
  • tol: time tolerance in ticks, >= 0. A pointing within tol of sclkdp is accepted.
  • ref: name or ID of the reference frame of the result.

The result is (cmat, clkout): cmat is an SMatrix{3,3} that rotates a vector from ref to the instrument frame, and clkout is the clock value, in ticks, of the pointing that was used. The result is nothing if no loaded CK segment gives a pointing; nothing takes the place of the found flag of CSPICE. Segments with and without angular velocity are searched in priority order.

If ref is not the frame of the segment, the matrix is changed with the rotation between the two frames at the epoch of clkout. This needs the SCLK kernel of the spacecraft, unless both frames are inertial.

Throws SpiceError(:valueoutofrange) if tol < 0. Throws SpiceError(:unknownframe) if ref is not a known frame name; ref is read only when a pointing is found. The change of frame throws the kinds of pxform, and the kinds of sct2e if the SCLK kernel is not loaded: ckfrot returns nothing in this case, and ckgp throws, both as in CSPICE.

Examples

furnsh("naif0012.tls"); furnsh("mission.tsc"); furnsh("mission.bc")
et = str2et("2026-10-16T12:00:00")
sclkdp = sce2c(-77, et)
r = ckgp(-77000, sclkdp, 0.0, "J2000")
if r !== nothing
    cmat, clkout = r
    boresight_j2000 = cmat' * [0.0, 0.0, 1.0]
end

See also ckgpav, ckcov, pxform.

source
Allspice.ckgpav — Function
ckgpav([ctx,] inst, sclkdp, tol, ref) -> Union{Nothing,Tuple{SMatrix,SVector,Float64}}

Return the pointing and the angular velocity of the instrument or structure inst at the encoded spacecraft clock value sclkdp, as ckgpav_c.

The result is (cmat, av, clkout), where av is an SVector{3}: the angular velocity of the instrument frame relative to ref, in rad/s, with components in ref. Only segments with angular velocity are used, and the result is nothing if none gives a pointing. The other arguments, results and errors are those of ckgp.

Allspice.ckcov — Function
ckcov([ctx,] ck, idcode, needav, level, tol, timsys) -> Window

Return the coverage Window of the instrument or structure idcode in the CK file ck, as ckcov_c.

The window holds the intervals on which the file gives a pointing, as sorted disjoint intervals; it is empty if the file has no data for idcode. wnfetd(w, i) gives interval i as (start, stop).

  • needav: true restricts the answer to segments with angular velocity.
  • level: "SEGMENT" gives the bounds in the segment descriptors; "INTERVAL" gives the intervals on which a pointing with tolerance zero exists.
  • tol: >= 0, in ticks. Each interval is widened by tol on both sides; the start does not go below zero.
  • timsys: "SCLK" gives encoded clock ticks; "TDB" gives seconds past J2000 TDB. "TDB" needs the SCLK kernel of the spacecraft in ctx.

The CK file is read from disk and need not be loaded.

Throws SpiceError(:valueoutofrange) if tol < 0, SpiceError(:invalidoption) if level is not one of the two, SpiceError(:notsupported) if timsys is not one of the two, the file errors of ckobj, and for "TDB" the errors of sct2e.

Examples

furnsh("naif0012.tls"); furnsh("mission.tsc")
for id in ckobj("mission.bc")
    w = ckcov("mission.bc", id, false, "INTERVAL", 0.0, "TDB")
    for i in 1:wncard(w)
        start, stop = wnfetd(w, i)
        println(id, ": ", et2utc(start, "ISOC", 0), " to ", et2utc(stop, "ISOC", 0))
    end
end

See also ckcov!, spkcov, pckcov.

Allspice.ckfrot — Function
ckfrot([ctx,] inst, et) -> Union{Nothing,Tuple{SMatrix{3,3},Int}}

Return the rotation from the CK frame of the instrument or structure inst to its base frame, the reference frame of the CK segment, at et, and the frame ID of the base frame, as ckfrot_c.

  • inst: CK ID (frame class ID) of the CK frame.
  • et: seconds past J2000 TDB.

For the result (rot, ref), rot * v gives in frame ref the components of a position v given in the CK frame. ref is the reference frame of the CK segment that gives the pointing: the clock of inst (see ckmeta) converts et to ticks, and the loaded segments of inst are searched in priority order with tolerance zero, with and without angular velocity. This is the link of the frame chain that pxform follows for a CK frame. As in pxform, et can be a dual number when ForwardDiff is loaded; the elements of rot then are dual numbers.

nothing takes the place of the found flag of CSPICE. The checks come in this order: SpiceError(:badarg) if et is not finite; nothing if no CK is loaded or the SCLK kernel of the clock is not loaded, as in CSPICE; SpiceError(:valueoutofrange) if et is outside the range of the clock; nothing if no segment covers et.

Examples

furnsh("naif0012.tls"); furnsh("mission.tsc"); furnsh("mission.bc")
et = str2et("2026-10-16T12:00:00")
r = ckfrot(-77000, et)
if r !== nothing
    rot, ref = r
    boresight = rot * [0.0, 0.0, 1.0]        # in the frame `ref`
end

See also ckfxfm, ckgp.

source
Allspice.ckfxfm — Function
ckfxfm([ctx,] inst, et) -> Union{Nothing,Tuple{SMatrix{6,6},Int}}

Return the state transformation from the CK frame of the instrument or structure inst to its base frame at et, and the frame ID of the base frame, as ckfxfm_c.

The matrix is [R 0; dR R]: R is the rotation of ckfrot, and dR (1/s) comes from the angular velocity of the CK segment, as sxform gives it for a CK frame. Only segments with angular velocity are searched, so the result is nothing also where only a segment without angular velocity covers et. The other nothing cases, the arguments and the errors are those of ckfrot, except that et is a plain number.

Records of C-kernel segments

These calls read one segment of an open CK file, given by its descriptor from a DAF search (dafbfs, daffna, dafgs).

Allspice.cknr02 — Function
cknr02(handle, descr) -> Int

Return the number of pointing records in the CK type 2 segment with the descriptor descr, as cknr02_c.

descr is the packed descriptor of the segment (5 doubles), as dafgs returns it during a search on handle. The count follows from the addresses in the descriptor, so the file is not read, and a closed handle gives the count too.

Throws SpiceError(:ckwrongdatatype) if the segment is not of type 2, and :dafinvalidparams if descr has fewer than 5 doubles.

Examples

h = dafopr("mission.bc")
dafbfs(h)
while daffna(h)
    descr = dafgs(h)
    _, ic = dafus(descr, 2, 6)
    ic[3] == 2 || continue
    for i in 1:cknr02(h, descr)
        start, stop, rate = ckgr02(h, descr, i)[1:3]
    end
end
dafcls(h)

See also ckgr02, cknr03.

Allspice.ckgr02 — Function
ckgr02(handle, descr, recno) -> Vector{Float64}

Return the pointing record recno of the CK type 2 segment with the descriptor descr in the file of handle, as ckgr02_c. Records count from 1, as in CSPICE.

The record has 10 doubles: the start and the stop of its interval (ticks), the clock rate (seconds per tick), the quaternion of the C-matrix at the start (SPICE form, scalar first) and the constant angular velocity (rad/s, components in the reference frame of the segment). descr is as in cknr02.

Throws SpiceError:

  • :ckwrongdatatype if the segment is not of type 2;
  • :cknonexistrec unless 1 <= recno <= cknr02(handle, descr);
  • :dafnosuchhandle if the handle is closed;
  • :dafinvalidparams if descr has fewer than 5 doubles.

Allspice.ckgr03 — Function
ckgr03(handle, descr, recno) -> Vector{Float64}

Return the pointing instance recno of the CK type 3 segment with the descriptor descr in the file of handle, as ckgr03_c. Records count from 1, as in CSPICE.

The record is the time tag (ticks) and the quaternion of the C-matrix (SPICE form, scalar first): 5 doubles for a segment without angular velocity, and 8 doubles, the last three the angular velocity (rad/s, components in the reference frame of the segment), for a segment with it. The fourth integer of the descriptor (see dafus) is 1 for a segment with angular velocity. descr is as in cknr02.

Throws SpiceError:

  • :ckwrongdatatype if the segment is not of type 3;
  • :cknonexistrec unless 1 <= recno <= cknr03(handle, descr);
  • :dafnosuchhandle if the handle is closed;
  • :dafinvalidparams if descr has fewer than 5 doubles.
