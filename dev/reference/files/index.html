Files and writers

A file handle is a DAFHandle or a DASHandle object, not an integer. The writers keep the positional arguments of CSPICE and take the context as the keyword ctx; other calls take it as the optional first argument [ctx,]. Without it a call uses default_context. [ctx | ks,] means that the call also accepts a KernelSet, the immutable snapshot of the kernels of a context that Allspice.kernelset(ctx) returns.

An input of the wrong shape throws SpiceError(:badarg).

DAF files

Allspice.DAFHandle — Type
DAFHandle

An open DAF file. It replaces the integer handle of CSPICE.

dafopr, dafopw, dafonw, spkopn, spkopa and ckopn return a handle. Close it with dafcls, spkcls, ckcls or close; isopen(handle) tells whether it is open.

The handle holds the state that CSPICE keeps in global tables: the array search (dafbfs, daffna, dafbbs, daffpa) and the array that is being added (dafbna, dafada, dafena). Two handles are independent, so two tasks can work on two handles at the same time. One handle is not safe for concurrent use: tasks that share a handle must hold a lock around every call.

A call on a closed handle throws SpiceError(:dafnosuchhandle); the close calls do nothing instead. A write call on a handle that is open for reading throws SpiceError(:dafinvalidaccess).

Allspice.dafopr — Function
dafopr(path) -> DAFHandle

Open the DAF file path for reading and return its handle, as dafopr_c.

The file can have either byte order. No array search is begun. Close the handle with dafcls.

Throws SpiceError:

  • :blankfilename if path is blank, :filenotfound if the file does not exist;
  • :filereadfailed if the file is shorter than one record (1024 bytes);
  • :filarchmismatch if the file is a DAS file, :unknownfilarc if it is neither a DAF nor a DAS file (a text kernel, for example);
  • :ftpxfererror if the file was damaged by a transfer in text mode;
  • :unknownbff if the binary file format of the file is not known, :unsupportedbff if it is a VAX format;
  • :dafinvalidparams if the summary format in the file record is not valid;
  • :fileopenfailed if the system cannot open the file.

Examples

Write an SPK file with one segment, then search it as a DAF:

julia> path = joinpath(mktempdir(), "example.bsp");

julia> h = spkopn(path, "example SPK");

julia> cdata = [[1.0, 0.5, 2.0, 0.0, 3.0, 0.0]];

julia> spkw02(h, 499, 4, "J2000", 0.0, 100.0, "mars", 100.0, cdata, 0.0)

julia> spkcls(h)

julia> h = dafopr(path);

julia> dafbfs(h)

julia> daffna(h)
true

julia> dc, ic = dafus(dafgs(h), 2, 6)   # see dafgs for the meaning of the components
([0.0, 100.0], [499, 4, 1, 2, 385, 396])

julia> dafgn(h)
"mars"

julia> dafgda(h, ic[5], ic[5] + 1)      # midpoint and radius of the first record, s
2-element Vector{Float64}:
 50.0
 50.0

julia> daffna(h)
false

julia> dafcls(h)

See also dafopw, dafbfs, dafgda, dafec, getfat.

dafopw(path) -> DAFHandle

Open the existing DAF file path for writing, as dafopw_c, to add arrays or comments.

The file must have the native byte order. Make sure that no other handle writes the same file. Unload the file from every context before the call and load it again after the close: a kernel that is loaded does not see arrays that are added later.

Allspice.dafonw — Function
dafonw(path, ftype, nd, ni, ifname, resv) -> DAFHandle

Create the DAF file path and open it for writing, as dafonw of SPICELIB.

  • ftype: the file type, for example "SPK". Four characters are stored.
  • nd, ni: the numbers of doubles and of integers in an array summary.
  • ifname: the internal file name. 60 characters are stored.
  • resv: the number of reserved records, which hold the comments.

The file is on disk when the call returns: the file record, resv comment records with an empty comment area, one empty summary record and one name record, byte for byte as CSPICE writes them. The byte order is the native one. An existing file is never replaced.

Throws SpiceError:

  • :blankfilename if path is blank;
  • :fileopenfailed if the file exists or cannot be created;
  • :blankfiletype if ftype is blank, :illegalcharacter if it has a character that is not printable;
  • :dafinvalidparams unless 0 <= nd <= 124, 2 <= ni <= 250 and nd + (ni + 1) ÷ 2 <= 125;
  • :dafnoresv if resv < 0.

See also spkopn, ckopn, dafbna, dafcls.

Allspice.dafgda — Function
dafgda(handle, first, last) -> Vector{Float64}

Return the doubles at the DAF addresses first:last, as dafgda_c. Addresses start at 1, as in CSPICE.

Two results differ from CSPICE:

  • A range that is not inside the file throws. CSPICE returns zeros without an error.
  • If the file ends inside its last record, the doubles of that record that the file holds are returned. CSPICE returns zeros for the whole record.

Throws SpiceError(:dafnegaddr) if first < 1, :dafbeggtend if first > last, and :filereadfailed if the range is not inside the file.

Allspice.dafbna — Function
dafbna(handle, sum, name) -> Nothing

Begin a new array in the DAF file of handle, as dafbna_c.

sum is the packed summary (dafps); dafena sets its two address components. name is the array name, cut or padded to 8 * (nd + (ni + 1) ÷ 2) characters (40 for an SPK or a CK file). Allspice.dafac — Function
dafac(handle, lines) -> Nothing

Append the comment lines lines to the comment area of the DAF file, as dafac_c.

Trailing blanks of a line are not stored. If the reserved records do not have room, records are added and the data of the file move. Every address that was read from a summary before the call is then stale, so read the summaries again.

Allspice.spkopn — Function
spkopn(path, ifname, ncomch=0) -> DAFHandle

Create the SPK file path and open it for writing, as spkopn_c.

ifname is the internal file name and ncomch is the number of comment characters to make room for. The file is on disk when the call returns, byte for byte the file that spkopn_c creates. An existing file is never replaced. Add segments with the spkwNN writers and close the handle with spkcls. Load the file with furnsh only after the close.

Throws SpiceError(:emptystring) if path or ifname is empty, and :fileopenfailed if the file exists or cannot be created.

Examples

Write a type 2 segment that has one record of degree 1, then load the file:

julia> path = joinpath(mktempdir(), "example.bsp");

julia> h = spkopn(path, "example SPK");

julia> cdata = [[1.0, 0.5, 2.0, 0.0, 3.0, 0.0]];    # coefficients of x, y, z

julia> spkw02(h, 499, 4, "J2000", 0.0, 100.0, "mars", 100.0, cdata, 0.0)

julia> spkcls(h)

julia> ctx = SpiceContext();

julia> furnsh(ctx, path)

julia> pos, lt = spkpos(ctx, 499, 100.0, "J2000", "NONE", 4);

julia> pos == [1.5, 2.0, 3.0]
true

See also spkopa, spkw02, spk14b, dafac to add comments.

Allspice.spkw02 — Function
spkw02(handle, body, center, frame, first, last, segid, intlen, cdata, btime;
       ctx=default_context()) -> Nothing

Write an SPK segment of type 2 (Chebyshev polynomials for the position, on intervals of equal length) to the file of handle, as spkw02_c.

Arguments

handle, body, center, frame, first, last, segid and ctx have the same meaning in every spkwNN writer.

  • handle: a DAFHandle from spkopn or spkopa.
  • body, center: NAIF IDs of the body and of its center of motion.
  • frame: the reference frame, a name or a frame ID. A name is resolved in ctx (a SpiceContext or a KernelSet); built-in frames need no kernel.
  • first, last: the coverage of the segment, seconds past J2000 TDB.
  • segid: the segment identifier, at most 40 printable characters.
  • intlen, btime: the length of every interval (s) and the start of the first interval (seconds past J2000 TDB).
  • cdata: one record for each interval, each with 3 * (polydg + 1) coefficients (km): those of x, then of y, then of z. The number of records n and the degree polydg follow from its shape.

A table such as cdata is a vector of vectors (the form of SPICE.jl) or a matrix with one record in each column. A table of states or of packets, whose record length the data type fixes, can also be a flat vector; cdata cannot. The record count that CSPICE takes as an argument is not an argument here: it follows from the input.

The segment is on disk when the call returns. It holds the same data as the segment that spkw02_c writes. A call that throws writes nothing.

Throws SpiceError. Every spkwNN writer throws:

  • :dafnosuchhandle if the handle is closed, :dafinvalidaccess if it is open for reading;
  • :emptystring if frame or segid is empty;
  • :badarg if the shape of an input does not fit;
  • :invalidrefframe if the frame is not known.

The other checks follow CSPICE writer by writer, so they differ between writers:

  • Only a writer that lists :barycenterephem and :bodyandcentersame, or the kinds of spkpds, rejects body == 0 and body == center.
  • first == last is accepted where the list says "if first > last".
  • A segid that is too long is :idstringtoolong in spkw02, spkw03 and spkw20, and :segidtoolong in the others.

spkw02 also throws:

  • :numcoeffsnotpos if cdata has no record;
  • :invaliddegree unless 0 <= polydg <= 27;
  • :intlennotpos unless intlen > 0;
  • :baddescrtimes if first > last;
  • :coveragegap unless [first, last] is inside [btime, btime + n * intlen], with the tolerance 1e-13 * max(abs(first), abs(last));
  • :idstringtoolong or :nonprintablechars if segid is not valid.

See spkopn for an example.

See also spkw01, spkw03, spkw05, spkw08, spkw09, spkw10, spkw12, spkw13, spkw15, spkw17, spkw18, spkw19, spkw20, spkw21, spk14b.

Allspice.DASHandle — Type
DASHandle

An open DAS file. It replaces the integer handle of CSPICE.

dasopr, dasopw, dasonw, dasops, dlaopn and dskopn return a handle. Close it with dascls, dskcls or close; isopen(handle) tells whether it is open.

The handle holds the three address spaces of the file in memory: characters, doubles and 32-bit integers, each numbered from 1. A handle that is open for writing changes this memory only, and the file on disk changes when dascls runs. The data of a handle that is open for reading are never modified.

A DAS file is segregated if all records of one data type are together. A file that is being written by CSPICE can have the types mixed.

Two handles are independent. One handle is not safe for concurrent use: tasks that share a handle must hold a lock around every call.

A call on a closed handle throws SpiceError(:dasnosuchhandle); the close calls do nothing instead. A write call on a handle that is open for reading throws SpiceError(:dasinvalidaccess).

Allspice.dskxsi — Function
dskxsi([ctx | ks,] pri, target, srflst, et, fixref, vertex, raydir)
    -> Union{Nothing,Tuple{SVector{3,Float64},DSKSegment,Int}}

Return (xpt, segment, plid) for the first point where the ray from vertex along raydir meets the surface that the loaded DSK segments of target define, as dskxsi_c, or nothing if there is no intercept.

Arguments

  • pri: must be false. All segments have the same priority and the nearest intercept wins.
  • target: body name or body ID.
  • srflst: surface IDs (a vector or a tuple); an empty list accepts every surface of the body.
  • et: epoch, seconds past J2000 TDB. It selects the segments by coverage, and the frames are evaluated at it.
  • fixref: name or ID of a body-fixed frame that is centered on the target.
  • vertex, raydir: the ray in the frame fixref; vertex is in km, relative to the center of the target.

xpt is in the frame fixref (km). segment is a DSKSegment and plid is the plate number, from 1. They replace the handle, the DLA descriptor, the DSK descriptor and the first element of ic of CSPICE; dc of CSPICE has no content for the data type 2. nothing replaces the found flag.

As in CSPICE, a ray that starts outside of the bounding sphere of the surface is searched from the point where it enters that sphere. For a ray through an edge or a vertex of the plates, plid can therefore differ from the plate that dskx02 returns for the same ray; xpt agrees to rounding.

The form with a context uses the tolerances of the context (dskstl). The form with a KernelSet uses the column "Value at start" of dskgtl. The call reads one snapshot of the loaded kernels and writes nothing, so many threads can call it while another thread loads kernels. With an integer target, an integer fixref and SVector arguments it does not allocate.

Throws SpiceError:

  • :badpriorityspec if pri is true, as CSPICE;
  • :idcodenotfound if the target or the frame is not known, :noframeinfo if the center of the frame is not known, :invalidframe if the frame is not centered on the target;
  • :nodsksegments if no DSK segment of the target is loaded, :dskdatanotfound if no loaded segment has a surface of srflst;
  • :rayiszerovector if raydir is zero.

See also dskxv, dskx02, latsrf, and dskw02 for an example.

Allspice.dskw02 — Function
dskw02([ctx,] handle, center, surfid, dclass, frame, corsys, corpar, mncor1, mxcor1,

Write a type 2 segment (triangular plates) to the DSK file of handle, as dskw02_c.

Arguments

  • handle: a DASHandle from dskopn.
  • center, surfid: the body ID and the surface ID.
  • dclass: the data class, 1 for a surface that each ray from the center meets one time, 2 for a general surface.
  • frame: the name or the ID of the frame of the vertices. A name that is not built in is looked up in the kernel pool of ctx (default: the default context).
  • corsys, corpar: the coordinate system of the bounds (1 latitudinal, 3 rectangular, 4 planetodetic) and its parameters; for system 4 these are the equatorial radius (km) and the flattening. corpar can have fewer than 10 elements; the rest is 0.

  • :frameidnotfound if the frame is not known;
  • :timesoutoforder unless first < last;

julia> dskw02(h, 499, 1, 2, "IAU_MARS", 1, zeros(10), -pi, pi, -pi / 2, pi / 2, mncor3,

julia> dladsc = dlabfs(h);

julia> dskz02(h, dladsc)

Allspice.dskmi2 — Function
dskmi2(vrtces, plates, finscl, corscl, worksz, voxpsz, voxlsz, makvtl, spxisz)
    -> (spaixd, spaixi)

Return the spatial index of a type 2 segment, as dskmi2_c: the double part spaixd (10 elements) and the integer part spaixi (spxisz elements). dskw02 takes both.

Arguments

  • vrtces, plates: the vertices (km) and the plates, each a 3 x n matrix or a vector of 3-vectors. A plate is three vertex numbers, which start at 1.
  • finscl: the edge length of a fine voxel, in units of the mean extent of the plates.
  • corscl: the number of fine voxels along one edge of a coarse voxel.
  • worksz: the size of the workspace. It must hold the pairs of a plate and a fine voxel that meet: np times the mean number of fine voxels that a plate meets. With makvtl it must also hold nv + 3np. The least value is np + 1.
  • voxpsz: the size of the voxel-plate pointer array, at least corscl^3 times the number of coarse voxels that are not empty.
  • voxlsz: the size of the voxel-plate list, at least the first bound of worksz. The least value is np + 1.
  • makvtl: true to make the vertex-plate list.
  • spxisz: the size of spaixi, at least 100007 + voxpsz + voxlsz, plus 2nv + 3np if makvtl is true.

The index is equal to the one that CSPICE makes.

Throws SpiceError:

  • :badfinevoxelscale unless finscl > 0, :badcoarsevoxscale unless corscl >= 1;
  • :badvertexcount or :badplatecount if the number of vertices or of plates is out of range;
  • :workspacetoosmall if worksz < np + 1, :ptrarraytoosmall if voxpsz < 1, :platelisttoosmall if voxlsz < np + 1, :intindextoosmall if spxisz is below its bound;

  • :valueoutofrange, :incompatiblescale or :coarsegridoverflow if the voxel grid that follows from the scales is not valid;
  • :badvertexindex if a vertex number is not in 1:nv, which CSPICE does not check here.
