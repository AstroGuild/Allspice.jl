Event kernels

An entry is the value of one column in one row: one element in a scalar column, one or more in an array column, or null in a column that allows nulls. A record is a row; the names of CSPICE use both words. Segments, rows, columns and elements count from 1 in every call of this page, where the C interface of CSPICE counts from 0. Sibling calls can throw different kinds for one condition, such as a wrong data type or an entry that was never written, because each kind is the one of the CSPICE routine that the call ports; see SpiceError.

Reading a file

Allspice.EKColumnAttr — Type
EKColumnAttr

Attributes of one EK column, as the attribute descriptor of ekcii_c and ekssum_c. ekcii and ekssum return it.

  • cclass: the column class of CSPICE, the code of the storage layout in the file: 1, 2 and 3 for scalar integer, double precision or time, and character columns; 4, 5 and 6 for array columns of these types; 7, 8 and 9 for scalar columns with FIXED_COUNT = TRUE (see ekbseg);
  • dtype: :CHR, :DP, :INT or :TIME;
  • strlen: the string length of a character column, -1 for strings of variable length, and 0 for a column of another type (CSPICE gives 1 there);
  • size: the number of values of an entry, -1 for entries of variable size;
  • indexd: true if the column has an index;
  • nullok: true if the column can hold null entries.

Allspice.ekopr — Function
ekopr(path) -> DASHandle

Open the EK file path for read access and return its handle, as ekopr_c.

The handle is a DASHandle. The caller owns it; close it with ekcls. The handle serves the calls that read one file (eknseg, ekssum, ekrcec, ekrced, ekrcei); the example of ekopn ends with such a read. To run queries, load the file with eklef instead.

Throws SpiceError(:filenotfound) if the file does not exist, the other kinds of dasopr if it is not a DAS file, SpiceError(:wrongarchitecture) if the DAS file is not an EK, and SpiceError(:invalidformat) if the EK is damaged.

See also ekopw, ekopn.

Allspice.ekrcec — Function
ekrcec(handle, segno, recno, column) -> (cvals::Vector{String}, isnull::Bool)

Return all strings of the entry of the character column column in row recno of segment segno, without trailing blanks, as ekrcec_c.

segno and recno count from 1; ekrcec_c counts from 0. The column name is matched without regard to case. The entry of a scalar column gives a vector of one string. A null entry gives an empty vector and isnull == true; for a null entry CSPICE gives a count of 1, or the size of a fixed-size array column, and values without meaning.

Throws SpiceError with the kind

  • :invalidindex if segno is not a segment of the file;
  • :bug if the segment has no column column;
  • :wrongdatatype if the column does not have character type;
  • :indexoutofrange unless 1 <= recno <= nrows;
  • :uninitialized if the entry was never written.

A closed handle gives the errors of eknseg.

See also ekrced, ekrcei, ekfind.

Writing

Allspice.EKFastLoad — Type
EKFastLoad <: AbstractVector{Int32}

The state of one fast load: the second result of ekifld, which ekaclc, ekacld, ekacli and ekffld take.

A fast load writes a segment column by column, where ekappr and ekacec write it row by row. The value takes the place of the rcptrs array of CSPICE: pass it on unchanged. CSPICE can do one fast load at a time; here every load has its own state, so several can run at once, on one handle or on several.

Allspice.ekopn — Function
ekopn(path, ifname, ncomch=0) -> DASHandle

Create the EK file path and return a handle that is open for write, as ekopn_c of CSPICE.

ifname is the internal file name and ncomch the number of comment characters to reserve. The new file holds no segment: start one with ekbseg or ekifld. Close the handle with ekcls; the data are on disk when ekcls returns.

Throws SpiceError(:emptystring) if path or ifname is empty, SpiceError(:invalidcount) if ncomch < 0, and SpiceError(:fileopenfailed) if path exists or cannot be created.

Examples

Write a segment with two rows record by record, then read it back. Segment and row numbers start at 1.

julia> path = joinpath(mktempdir(), "example.bes");

julia> h = ekopn(path, "example EK");

julia> seg = ekbseg(h, "OBSERVATIONS", ["ID", "TARGET", "RANGE"],
           ["DATATYPE = INTEGER, INDEXED = TRUE",
            "DATATYPE = CHARACTER*(16), NULLS_OK = TRUE",
            "DATATYPE = DOUBLE PRECISION, SIZE = 2"])
1

julia> row = ekappr(h, seg)
1

julia> ekacei(h, seg, row, "ID", [42])

julia> ekacec(h, seg, row, "TARGET", ["MOON"])

julia> ekaced(h, seg, row, "RANGE", [356.5e3, 406.7e3])

julia> row = ekappr(h, seg)
2

julia> ekacei(h, seg, row, "ID", [43])

julia> ekacec(h, seg, row, "TARGET", String[], true)    # a null entry

julia> ekaced(h, seg, row, "RANGE", [0.0, 1.0])

julia> ekcls(h)

julia> h = ekopr(path);

julia> eknseg(h), ekssum(h, 1).nrows
(1, 2)

julia> ekrcei(h, 1, 1, "ID")
([42], false)

julia> ekrced(h, 1, 1, "RANGE")
([356500.0, 406700.0], false)

julia> ekrcec(h, 1, 1, "TARGET"), ekrcec(h, 1, 2, "TARGET")
((["MOON"], false), (String[], true))

julia> ekcls(h)

See also ekopw, ekops, ekbseg, ekappr, ekacec, ekfind.

Allspice.ekbseg — Function
ekbseg(handle, tabnam, cnames, decls) -> segno

Start a new segment without rows for the table tabnam in the EK of the write handle and return its segment number, as ekbseg_c of CSPICE.

Segment numbers start at 1; the C interface of CSPICE counts from 0. cnames holds the column names and decls one declaration for each column. A table name has at most 64 and a column name at most 32 characters: a letter, then letters, digits, $ and _. The file stores the names in upper case. Two columns with the same name are not refused; a call that names the column then reaches the first of them.

A declaration is a list of KEYWORD = value items that commas separate, in any case:

  • DATATYPE (required): INTEGER, DOUBLE PRECISION, TIME, CHARACTER*(n) (strings of at most n characters) or CHARACTER*(*) (strings of any length).
  • SIZE: the number of elements of an entry, or VARIABLE. Default 1. VARIABLE is not valid with CHARACTER*(*).
  • INDEXED: TRUE or FALSE. Default FALSE. Scalar columns only.
  • NULLS_OK: TRUE or FALSE. Default FALSE.
  • FIXED_COUNT: TRUE or FALSE. Default FALSE. Scalar columns only, and for all columns of the segment or for none. No row of a segment of such fixed-count columns can be added or deleted, so ekbseg makes a segment that stays empty, as in CSPICE: declare them with ekifld.

Add rows with ekappr or ekinsr.

Throws SpiceError with the kind:

  • :dasnosuchhandle or :dasinvalidaccess if the handle is closed or open for read;
  • :emptystring, :idstringtoolong, :nonprintablechars or :invalidname for a name that does not follow the rules;
  • :invalidcount unless there are 1 to 100 columns and as many declarations;
  • :badcolumndecl for a declaration that does not follow the rules, and :badcolumdecl (the spelling of CSPICE) if DATATYPE is absent;
  • :badattributes if only some of the columns have FIXED_COUNT = TRUE.

See the example of ekopn.

Allspice.ekinsr — Function
ekinsr(handle, segno, recno) -> Nothing

Allspice.ekacec — Function
ekacec(handle, segno, recno, column, cvals, isnull=false) -> Nothing

Write the entry of the character column column in row recno of segment segno, as ekacec_c of CSPICE.

cvals is a vector with the strings of the entry. A scalar column takes the first string (a blank string if cvals is empty); an array column takes all of them. Trailing blanks do not count, and a string longer than the string length of the column is cut. With isnull = true the entry is null and no string is stored, but an array column still checks the number of strings, as in CSPICE. The column name can be in any case.

Use the call for an entry that is not written yet, and ekucec to replace an entry. A second call for one entry throws. CSPICE makes this check only for a scalar numeric column; for the other columns it writes the entry again and leaves the pages of the first one in use.

Throws SpiceError with the kind:

  • :dasnosuchhandle or :dasinvalidaccess if the handle is closed or open for read;
  • :invalidindex if there is no segment segno;
  • :bug if the segment has no column column, and :wrongdatatype if the column does not have character type;
  • :indexoutofrange if there is no row recno;
  • :badattribute if isnull is true and the column does not allow nulls;
  • :invalidcount if an array column gets no string, or a number of strings other than its declared size (SIZE = VARIABLE accepts any number from 1);
  • :nonemptyentry if the entry is written already.

See the example of ekopn. See also ekaced, ekacei, ekrcec.

Allspice.ekifld — Function
ekifld(handle, tabnam, nrows, cnames, decls) -> (segno, rcptrs::EKFastLoad)

Start a new segment of nrows rows that is written column by column, as ekifld_c of CSPICE. Return the segment number (from 1) and the state of the load.

tabnam, cnames and decls are those of ekbseg. Store every column exactly once with ekaclc, ekacld or ekacli, then call ekffld; pass rcptrs to each of these calls. Until ekffld the segment cannot be read or extended. ekcls before ekffld closes the file without an error, as in CSPICE, but the file then holds a segment that eklef refuses. Other segments of the file can be changed meanwhile, which CSPICE does not allow.

If the columns are declared with FIXED_COUNT = TRUE, the number of rows is fixed: ekappr, ekinsr and ekdelr refuse the segment.

Throws SpiceError(:invalidcount) if nrows < 1, and the errors of ekbseg.

Examples

A scalar column needs no entry sizes, and a column that does not allow nulls needs no null flags. The null row 2 of XY still takes the room of its entry size in the values.

julia> h = ekops();

julia> seg, rcptrs = ekifld(h, "POINTS", 3, ["ID", "XY"],
           ["DATATYPE = INTEGER, INDEXED = TRUE",
            "DATATYPE = DOUBLE PRECISION, SIZE = VARIABLE, NULLS_OK = TRUE"]);

julia> ekacli(h, seg, "ID", [10, 20, 30], Int[], Bool[], rcptrs)

julia> ekacld(h, seg, "XY", [1.0, 2.0, 0.0, 3.0], [2, 1, 1], [false, true, false], rcptrs)

julia> ekffld(h, seg, rcptrs)

julia> ekrcei(h, seg, 3, "ID")
([30], false)

julia> ekrced(h, seg, 1, "XY"), ekrced(h, seg, 2, "XY"), ekrced(h, seg, 3, "XY")
(([1.0, 2.0], false), (Float64[], true), ([3.0], false))

julia> ekcls(h)

Allspice.ekaclc — Function
ekaclc(handle, segno, column, cvals, entszs, nlflgs, rcptrs) -> Nothing

Store the whole character column column of the segment that ekifld started, as ekaclc_c of CSPICE.

  • cvals: the strings of all rows in row order (for an array column the strings of row 1, then those of row 2, and so on). A null row also takes the room of its entry.
  • entszs[r]: the number of strings of row r, at least 0; a row of size 0 that is not null holds an empty entry. Used only for a column with SIZE = VARIABLE.
  • nlflgs[r]: true if row r is null. Used only for a column that allows nulls.
  • rcptrs: the second result of ekifld.

Trailing blanks do not count, and a string longer than the string length of the column is cut.

Throws SpiceError with the kind:

  • :dasnosuchhandle or :dasinvalidaccess if the handle is closed or open for read;
  • :invalidindex if there is no segment segno;
  • :wrongsegment if rcptrs belongs to another fast load;
  • :bug if the segment has no column column, and :wrongdatatype if the column does not have character type;
  • :invalidcount if cvals has fewer strings than the rows need, or if entszs or nlflgs, where the column uses it, has fewer elements than rows (CSPICE cannot make this check);
  • :outofrange if an entry size is negative, and :invalidcount if that row is null (CSPICE reads outside cvals);
  • :columnstoredtwice if this fast load stored the column already (CSPICE has no check and writes a segment that cannot be read);
  • :invalidsize if a fixed-count column has a string length outside 1 to 1014.

See also ekacld, ekacli, ekffld.

Queries

Allspice.EKResult — Type
EKResult

The result of one ekfind: the rows that satisfy the query, in the order of the ORDER BY clause, and the columns of the SELECT clause. It takes the place of the global result of the last query in CSPICE.

Read it with ekgc, ekgd, ekgi, eknelt and ekcolumn, with rows and SELECT columns that count from 1.

  • nmrows: the number of matching rows; length(result) gives the same.
  • seltype: the data type of each SELECT column, :CHR, :DP, :INT or :TIME.
  • selname: the name of each SELECT column, as TABLE.COLUMN in upper case.

The other fields are internal. A result stays valid after the EK files are unloaded, and many tasks can read one result at the same time. It is never modified.

Examples

result, failed, errmsg = ekfind("SELECT NAME, RADIUS FROM MOONS ORDER BY NAME")
failed && throw(ArgumentError(errmsg))
for row in 1:length(result)
    name, _, _ = ekgc(result, 1, row)
    radius, isnull, _ = ekgd(result, 2, row)
    println(name, " ", isnull ? "unknown" : radius)
end

Allspice.eklef — Function
eklef([ctx,] path) -> String

Load the EK file at path for queries, as eklef_c, and return the value to pass to ekuef.

The result is the path itself, not an integer handle as in CSPICE. It is not a DASHandle: ekcls, eknseg and the calls that read one file do not take it. The call has the effect of furnsh on a file that is an EK.

All segments of a table must have columns with the same names and attributes.

Throws SpiceError(:emptystring) if path is empty, SpiceError(:blankfilename) if it holds only blanks, SpiceError(:filenotfound) if the file does not exist, SpiceError(:wrongarchitecture) if it is not an EK, and SpiceError(:ekcolnummismatch), SpiceError(:ekmissingcolumn) or SpiceError(:badattributes) if a segment of the file does not have the columns of a loaded table of the same name. After an error the context is unchanged.

See also ekfind, ekntab.

Allspice.ekpsel — Function
ekpsel([ctx,] query) -> NamedTuple

Return the description of the SELECT clause of query, as ekpsel_c, in the named tuple (n, xbegs, xends, xtypes, xclass, tabs, cols, failed, errmsg).

  • n: the number of SELECT items. The vectors have one element for each item.
  • xbegs, xends: first and last byte of the item in query, from 1 (ekpsel_c counts from 0). A qualified name runs from the qualifier to the column name.
  • xtypes: the data type, :CHR, :DP, :INT or :TIME.
  • xclass: the class of the item, always :COL (a column).
  • tabs, cols: the table name (never the alias) and the column name, in upper case.
  • failed, errmsg: the error flag and the message of CSPICE for the query.

A query that is not valid gives failed == true, n == 0 and empty vectors; the call does not throw for it. The query is checked against the loaded tables, as in ekfind.

Allspice.ekfind — Function
ekfind([ctx,] query) -> (result::EKResult, failed::Bool, errmsg::String)

Find the rows of the loaded EK tables that satisfy query, as ekfind_c, and return them in an EKResult with the error flag and the error message of the query.

The query has the form SELECT <column>, ... FROM <table> [<alias>], ... [WHERE <constraints>] [ORDER BY <column> [ASC|DESC], ...]. The language is the one of CSPICE; the EK Required Reading of NAIF (https://naif.jpl.nasa.gov/pub/naif/toolkit_docs/C/req/ek.html) describes the constraints.

CSPICE keeps the rows of the last query in global state. Here the rows are in result, an EKResult, which the fetch calls take as first argument. Rows, SELECT columns and elements count from 1; CSPICE counts from 0.

A query that is not valid gives failed == true, the message of CSPICE in errmsg and a result without rows; the call does not throw for it. Positions in a message are byte positions in query, from 1. A time value in a query is converted with the leap-second and clock kernels of the context. A failure of that conversion is also reported in errmsg.

The call changes nothing, so many tasks can run queries at the same time, also while another task loads or unloads kernels.

The rows differ from those of CSPICE N0067 only where CSPICE has a defect:

  • a row that several OR branches of the WHERE clause match: CSPICE can return it twice, or drop other rows;
  • a double precision value compared with an indexed integer column: ID < 17.4 loses the rows with ID = 17 in CSPICE;
  • a number such as 2.756: the number parser of CSPICE gives a value that is wrong by one unit in the last place.

Throws SpiceError for a query that is over a size limit:

  • :celltoosmall if the WHERE clause expands to more than 1000 constraints (fewer if the query has other clauses);
  • :toomanyconjunctions if it expands to more than 1000 OR branches;
  • :buffertoosmall if it holds more than 100 time values.

Examples

julia> path = joinpath(mktempdir(), "moons.bes");

julia> h = ekopn(path, "moons");

julia> seg = ekbseg(h, "MOONS", ["NAME", "PLANET", "RADIUS"],
           ["DATATYPE = CHARACTER*(16)", "DATATYPE = INTEGER",
            "DATATYPE = DOUBLE PRECISION, NULLS_OK = TRUE"]);

julia> for (name, planet, radius) in (("PHOBOS", 4, 11.1), ("DEIMOS", 4, nothing), ("IO", 5, 1821.6))
           row = ekappr(h, seg)
           ekacec(h, seg, row, "NAME", [name])
           ekacei(h, seg, row, "PLANET", [planet])
           if radius === nothing
               ekaced(h, seg, row, "RADIUS", Float64[], true)   # null entry
           else
               ekaced(h, seg, row, "RADIUS", [radius])
           end
       end

julia> ekcls(h)

julia> ctx = SpiceContext();

julia> eklef(ctx, path);

julia> result, failed, errmsg = ekfind(ctx, "SELECT NAME, RADIUS FROM MOONS WHERE PLANET = 4 ORDER BY NAME");

julia> failed
false

julia> result
EKResult(2 rows, columns MOONS.NAME, MOONS.RADIUS)

julia> ekgc(result, 1, 2)      # SELECT column 1, row 2: (value, null, found)

julia> ekgd(result, 2, 1)      # the radius of DEIMOS is null
(0.0, true, true)

julia> ekcolumn(result, 2)

julia> ekfind(ctx, "SELECT NAME FROM MOONS WHERE")[2:3]

Allspice.eknelt — Function
eknelt(result, selidx, row) -> Int

Return the number of elements of the entry in row row and SELECT column selidx of result, as eknelt_c.

selidx and row count from 1; eknelt_c counts from 0. The result is 1 for a scalar column and the entry size for an array column of fixed size, also when the entry is null. A null entry of an array column of variable size has 1 element, as in CSPICE, although ekrcec and its siblings return no element for it.

Throws SpiceError(:invalidindex) unless 1 <= row <= result.nmrows and selidx is the position of a SELECT column.

See also ekfind, ekcolumn.

Allspice.ekgc — Function
ekgc(result, selidx, row, elment=1) -> (cdata::String, null::Bool, found::Bool)

Return element elment of the character entry in row row and SELECT column selidx of result, without trailing blanks, as ekgc_c.

selidx, row and elment count from 1; ekgc_c counts from 0. null is true if the entry is null; cdata is then empty and found is true. found is false if an array entry has fewer than elment elements. For a scalar column elment is not used, and found is true. The three results keep the form of CSPICE because a null entry and a missing element are two different cases.

Throws SpiceError(:invalidindex) unless 1 <= row <= result.nmrows, selidx is the position of a SELECT column and elment >= 1, SpiceError(:invalidtype) if the column does not have character type, and SpiceError(:uninitialized) if the entry was never written.

See ekfind for an example. See also ekgd, ekgi, eknelt, ekcolumn.

Allspice.ekcolumn — Function
ekcolumn(result, selidx) -> Vector

Return all entries of the SELECT column selidx (from 1) of result, one item for each row, in the order of the result.

An item is missing for a null entry, the value for a scalar column, and the vector of the values for an array column. Strings are without trailing blanks; a time is in seconds past J2000 TDB. The element type is the narrowest that holds the items, for example Vector{Union{Missing, Float64}}. This call has no CSPICE counterpart. It replaces the loop over eknelt and ekgc, ekgd or ekgi.

Throws SpiceError(:invalidindex) unless selidx is the position of a SELECT column. If an entry was never written, throws SpiceError(:uninitialized) for a character column and SpiceError(:uninitializedvalue) for another column.

See ekfind for an example.
