How the results were checked

CSPICE itself is the reference. The test suite calls each routine of this package and the routine of the same name in CSPICE, through SPICE.jl, on the same input, and compares the two results; it does not compare with stored numbers. The input is kernels from NAIF (planetary ephemerides, lunar orientation, leap seconds, constants) and kernels that the tests write with the CSPICE writers, so that every data type has a case.

Kind of checkWhat it compares
DifferentialA result of this package with the result of CSPICE for the same call
FileA kernel that this package wrote with the kernel that CSPICE wrote, byte for byte
DerivativeThe first derivative with the velocity of CSPICE, and each higher derivative with automatic differentiation of the one below it
ErrorThe kind of the error, and the text of the message where a program can depend on it
ConcurrencyAnswers from many threads during changes of the loaded kernels with the answers of one thread
AllocationA static proof (AllocCheck.jl) that 61 numeric routines cannot allocate: vector, matrix, rotation, coordinate and ellipsoid calls, conic elements, unitim, deltet and the table queries (list)
MeasureValue
Comparisons in the default runabout 40,000
Comparisons in the exhaustive run (ALLSPICE_TEST_FULL=1), with larger samples, longer search spans and larger filesabout 100,000
Line coverage of src/96.6 %
Julia versions tested1.10 and 1.13

Known limits of accuracy

A result that differs from CSPICE differs by rounding. For the states of the Moon and the planets from de440s.bsp, in inertial and body-fixed frames, the default run measures the following.

QuantityAberration correctionsLargest relative difference from CSPICE
Position, velocity and light timeall nine (NONE to XCN+S)7.3e-16

Three limits hold in CSPICE as well as in this package, because they come from the size of a number or from the method of CSPICE. The rotation angle of the Earth in IAU_EARTH grows with time and is about 50,000 radians in this century, so that the rounding of that angle alone moves the Sun by some meters in the frame. An aberration-corrected position has steps of some millimeters at the boundaries between the records of an SPK, because the target is evaluated at an earlier epoch than the observer, so that the two cross a boundary at different times. spkezr and spkpos differ from each other by up to 2e-11 relative with the converged corrections (CN, CN+S, which iterate the light-time equation until it converges), because the two routines stop their iterations by different rules.
