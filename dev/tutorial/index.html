First session

This page goes through one complete session: it loads kernels, converts a time, asks for a state and a rotation, finds the point of the Earth below a spacecraft, and searches for the times of perigee. Each call has the name that it has in CSPICE, without the _c suffix and with ! for a call that changes its argument.

Load kernels

A kernel is a file of data: an SPK holds trajectories in segments, each of which gives one body relative to a center over an interval of time, and a text kernel holds constants such as leap seconds and body radii. furnsh loads a kernel of any kind, and ktotal counts the loaded kernels of one kind or of all kinds. In the block below, kernels is a vector of three paths.

using Allspice

foreach(furnsh, kernels)      # leap seconds, constants of the Sun and the Earth, an SPK
ktotal("ALL")
3

A meta-kernel is a text kernel that lists other kernels in its variable KERNELS_TO_LOAD. furnsh(meta) loads each listed file into the default context, and furnsh(ctx, meta) loads them into the context ctx (see Contexts and threads). As in CSPICE, a relative path in the list is relative to the working directory of Julia, not to the directory of the meta-kernel. The variables PATH_SYMBOLS and PATH_VALUES give a name to a directory, and an entry that begins with $NAME starts with that directory.

The kernels of real bodies come from NAIF. The package SPICEKernels.jl downloads the generic kernels of NAIF on first use and returns their paths, which furnsh takes as they are:

using SPICEKernels

furnsh(naif0012_tls())   # leap seconds
furnsh(de440s())         # planets, Moon and Sun, 1849 to 2150
furnsh(pck00011())       # orientation and radii of the bodies

Convert a time

The state, frame, geometry and event calls take an epoch as seconds past J2000 in Barycentric Dynamical Time (TDB), which SPICE calls ET; the CK calls take encoded spacecraft clock instead. str2et converts a calendar string to that number. timout converts back with a picture, which is a string that shows the wanted format; the marker ::TDB asks for the TDB time scale.

et = str2et("2025 MAR 01 12:00:00 UTC")
7.941024691853893e8
timout(et, "YYYY Mon DD HR:MN:SC.### ::TDB")
"2025 Mar 01 12:01:09.185"

The input string and the output string differ by 69.185 seconds, which is the difference between TDB and UTC at that date.

State of a body

spkezr returns the state of a target relative to an observer, as a position in kilometers and a velocity in kilometers per second, together with the one-way light time in seconds. The frame and the aberration correction are arguments: "NONE" gives the geometric state, and "LT+S" gives the state that the observer sees, corrected for light time and stellar aberration.

state, lt = spkezr("PROBE", et, "J2000", "NONE", "EARTH")
state
6-element StaticArraysCore.SVector{6, Float64} with indices SOneTo(6):
 -25386.153654167378
   3798.1095549445336
  10439.640397850508
      1.6495610692719271
     -2.653083994095216
     -1.6791978258568458

The result is a static vector of six numbers; with names in upper case, as here, the call allocates no memory. spkpos returns the position alone:

sun, lt_sun = spkpos("SUN", et, "J2000", "LT+S", "PROBE")
lt_sun                        # seconds from the Sun to the spacecraft
499.09303254200233

Rotation between frames

pxform returns the matrix that rotates a vector from one frame to another at an epoch, and sxform returns the 6 by 6 matrix that also transforms the velocity. IAU_EARTH is the frame that rotates with the Earth.

r = pxform("J2000", "IAU_EARTH", et)
r * state[1:3]                # the position in the rotating frame, km
3-element StaticArraysCore.SVector{3, Float64} with indices SOneTo(3):
 -25098.479950465102
  -5499.336364979118
  10377.481818905228

The point below the spacecraft

subpnt returns the point of a body that is nearest to an observer, in the body-fixed frame; the method string selects the nearest point on the ellipsoid whose radii the constants kernel gives. The call also returns the epoch at the body and the vector from the observer to the point. reclat converts it to radius, longitude and latitude in radians, and dpr() is the number of degrees in a radian.

point, epoch, vector = subpnt("NEAR POINT/ELLIPSOID", "EARTH", et, "IAU_EARTH", "NONE", "PROBE")
radius, lon, lat = reclat(point)
(lon * dpr(), lat * dpr())    # degrees
(-167.64121130971648, 21.89048118925036)

Search for an event

The geometry finder calls (names that begin with gf) search an interval of time for the epochs at which a quantity meets a condition. The interval and the result are both a Window, which is a list of disjoint intervals. The search below looks for the local minima ("LOCMIN") of the distance from the Earth during one day. The two zeros are the reference value of a comparison such as ">" and the adjustment, which widens an absolute extremum to the times within that amount of it; a local minimum uses neither, and 600 seconds is the step of the search; The step says how to choose it.

search = Window()
wninsd!(search, et, et + 86400.0)
perigees = gfdist("PROBE", "NONE", "EARTH", "LOCMIN", 0.0, 0.0, 600.0, search)

for i in 1:wncard(perigees)
    t, _ = wnfetd(perigees, i)
    distance = vnorm(spkpos("PROBE", t, "J2000", "NONE", "EARTH")[1])
    println(timout(t, "YYYY Mon DD HR:MN:SC ::TDB"), "   ", round(distance; digits=3), " km")
end
2025 Mar 01 13:47:52   7078.137 km
2025 Mar 02 00:28:40   7078.137 km
2025 Mar 02 11:09:28   7078.137 km

The orbit of the example has a perigee radius of 7078.137 km, which the search recovers three times in the day.

Unload

kclear removes all kernels, and unload removes one file, or a meta-kernel with the files that it loaded.

kclear()
ktotal("ALL")
0

Errors

A call that cannot answer throws a SpiceError whose kind field names the reason and whose msg field holds the text; CSPICE would set its error flag instead. With no kernel loaded, the name of the spacecraft is unknown:

try
    spkezr("PROBE", et, "J2000", "NONE", "EARTH")
catch err
    err.kind
end
:idcodenotfound

A query that the loaded SPK files cannot answer throws the subtype SpkInsufficientDataError. Its fields target and observer hold the two bodies, et the epoch, body the body without data, and loaded whether that body has data at other epochs, so that a program can load another kernel or skip the epoch without reading the text.
